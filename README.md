# GD32 Project

#### 介绍
1.使用gd32f303 cl 作为usb doggle，上位机发指令给mcu，mcu 转发给芯片端。
2. 使用AT 指令，作为上位机 和mcu 的交互指令。
3.目前集成iic ，spi，swire 通讯 的相关指令。
